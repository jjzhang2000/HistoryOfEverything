## 🔧 手动验证指南

### Web 端手动测试步骤

1. **打开应用**
   ```bash

   flutter run -d chrome
   ```

2. **验证主菜单**
   - [ ] 菜单列表正常显示
   - [ ] 主题缩略图加载正常
   - [ ] 点击菜单项进入时间线

3. **验证时间线**
   - [ ] 时间线条目渲染正常

5. **验证收藏功能**
   - [ ] 点击收藏按钮切换状态
